Specialists, not one general agent

Each agent owns one creative responsibility. The Caption Director works with the transcript and the clip’s editorial structure. The Caption Design Agent creates reusable visual themes. The Music Agent reasons about eligible recordings and musical windows. RAVA’s multimodal Director chooses subjects and framing from perception evidence.

They share one principle: the model makes a bounded creative decision, and application code owns authorization, state changes, geometry, timing and persistence. Outputs pass through typed tools, compilers or candidate workflows before they touch the editor.

Agents compose through public interfaces. When allowed, the Caption Director asks the Caption Design Agent for a bespoke theme and applies the result through the ordinary caption system — an editorial agent handing a design brief to a design agent.

Bounded execution and recovery

The caption runtime allows at most 24 tool steps and 24 model calls; the worker runs with lower defaults of 16 and 18. Planned decisions and tool observations are stored in durable job checkpoints. If a worker is interrupted, it resumes by executing the checkpointed decision instead of asking the model for a new one.

Every edit command gets a deterministic identity derived from the run, step, tool and arguments, so a replay resolves to the original authoring receipt rather than creating a second edit.

Errors the model may repair — and errors it may not

Invalid tool arguments come back to the model as observations it can use to repair its next action. Authorization failures, concurrency conflicts and provider errors stay application failures. A creative repair loop must never treat a denied write as an invitation to try variations.

Waiting for transcription

Speech recognition is a separate durable job. If the caption agent needs a transcript, it defers, releases its worker claim, and resumes with the result. It reuses aligned captions when they already exist. Completion requires a final inspection of the editor revision, and the worker verifies that an editable caption track actually exists.

The Music Agent

An eight-step, eight-call loop reasons over the edited timeline and pinned track observations — beats, sections, energy, loudness — and chooses an eligible recording and musical moment, or decides no music fits. Code owns timing, gain, ducking and the compiled operations. The editor lets the creator audition Current against Proposed and accept an audio-only proposal through the authoring gateway. Automatic music in production stays gated by catalog eligibility.

Implementation notes

A provider limit that reshaped the protocol

Sending the union of every tool’s argument schema exceeded the structured-output limits of Gemini. The agent instead returns a small decision envelope with JSON-encoded arguments, which are validated against the chosen tool’s strict local model — manageable provider output, full validation kept.

What the guarantees do not cover

Checkpoints and command identities prevent duplicate edits; they do not make external model inference exactly-once across every crash boundary.
