The challenge

Making AI output usable beyond a demo. Models needed bounded tools, meaningful feedback, recoverable jobs, and a clear path from a creative decision to a reproducible edit. I worked across that path: model orchestration, compiler validation, browser previews, native rendering, revision history and deployment.

One principle runs through the system: models make bounded creative decisions; application code owns authorization, state, geometry, timing and persistence. No agent has direct database access.

Underneath it is a typed composition layer I designed: a graph of media, perception and composition with versioned schemas and pinned evidence, which the editor, agents and renderer all read the same way.

Case studies

  1. A typed foundation for media, perception and compositionThe composition layer: a typed property graph with versioned schemas, three-valued validation, pinned evidence and exact time — the model agents, editor and renderer share.
  2. Agents inside an editable media systemFour specialist agents — caption direction, caption design, music, reframing — with bounded tools, durable checkpoints and recovery that never re-asks the model.
  3. A language and compiler for caption motionA typed motion language, a compiler into the editor’s caption engine, a repair loop for generated themes, and one motion model shared by preview and export.
  4. Multimodal selection and reframingFast and Deep clip selection that controls inference depth, and reframing where a multimodal model chooses subjects and code computes the camera.
  5. Authoring, orchestration and infrastructureOne accepted revision history for human and AI edits, durable job execution on AWS, metered model operations, and publishing that is safe to retry.

Research method

The strongest engineering came from failures in real execution, each with an implemented consequence:

  • Provider schema limits changed the agent protocol to a small decision envelope with locally validated arguments.
  • Imperceptible motion led to deterministic amplitude and duration checks on generated themes.
  • Repetitive themes led to motion-graph comparison between variants.
  • Preview/export mismatches led to evaluator and layout fixes across the TypeScript and Python renderers.
  • Expensive selection retries led to durable stage reuse keyed by input hashes.
