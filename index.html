Clyflo

An AI-assisted video creation and editing platform I founded and built — from its core data model and editing agents to clip selection, reframing, publishing and the infrastructure that runs it. The full engineering story.

Agentic Editing & Captions

  1. 01Agents use only checked tools
  2. 02Resume after interruptions
  3. 03Caption style language and compiler
  4. 04Same result in preview and export
Problem
AI-generated edits and caption animation are only useful if they can be checked, edited and reproduced — and an agent interrupted mid-task must not repeat or retry an action it was refused.
Decision
Agents act only through typed, validated tools with fixed budgets and saved checkpoints. Caption motion is written in a small declarative language and compiled into the editor’s own caption engine, not generated as free-form code.
Evidence
Four specialist agents and brief-to-caption-theme generation shipped in the 30 October 2026 release. Preview and export evaluate the same motion within a 1e−6 tolerance.
Read: a language and compiler for caption motion

Multimodal Discovery & Reframing

  1. 01Fast and Deep clip selection
  2. 02Face and speaker tracking
  3. 03The model chooses the subject
  4. 04Code computes the crop
Problem
Long recordings are expensive to analyse, and a fixed vertical crop loses whoever is speaking.
Decision
Two selection paths, Fast and Deep, control how much multimodal analysis each source receives. For reframing, the model decides who should be in frame and deterministic code computes the editable camera path.
Evidence
One multimodal round replaced five sequential model stages. Both selection paths and both reframing paths (classical and model-directed) shipped in the October 2026 release, with replay tooling to compare vision models.
Read: multimodal selection and reframing

Platform Architecture & Infrastructure

  1. 01One gateway for every edit
  2. 02Jobs that survive crashes
  3. 03Separate worker pools on AWS
  4. 04Publishing that is safe to retry
Problem
Manual edits, agents and background jobs all change the same clip; workers crash; external platforms fail ambiguously.
Decision
Every edit goes through one revision-checked authoring gateway. Jobs live in PostgreSQL with leases and recovery. Publishing keeps separate state for each destination, so one failure cannot erase another result.
Evidence
Deployed on AWS ECS on 30 October 2026 through CI, with a database snapshot, migrations, readiness and smoke checks. Stale edits are rejected, and an identical retry returns the original receipt.
Read: authoring, orchestration and infrastructure
