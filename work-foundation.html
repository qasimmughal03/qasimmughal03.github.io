Why a graph, and why typed

A clip is not a flat timeline. It is a composition of sequences and tracks — visual, audio, caption and graphics — whose placements, caption cues and tokens, and framing windows with crop trajectories all refer back to sources and to perception: who is speaking, where a face is, what a transcript says. I built Clyflo’s model of that as a typed property graph, so every relationship is explicit and checkable rather than buried in ad-hoc JSON.

The kernel is deliberately small and pure: no storage, domain, network or application imports. It supports nominal node types with interfaces and at most one concrete base, typed edges with directional cardinalities and optional acyclicity, and closed, strictly typed properties — strict booleans, signed int64, finite floats, exact Decimals, enums, nested records and typed references. There is intentionally no query engine, reasoner or plugin loader: the foundation’s job is meaning and validation, not cleverness.

Partial knowledge is not absence

The most important design decision is the validator’s third answer. A check returns valid only when every requested structural fact was established, invalid when a violation is observed — even in a partial view — and incomplete when the facts needed are unavailable. Coverage is an explicit assertion from the host: a partial view cannot prove a reference is absent, satisfy a lower cardinality bound, or show the absence of cycles.

That matters for AI systems in particular. An agent reading a bounded window of a long clip must not conclude that a speaker “isn’t there” because it wasn’t loaded. Projections for the editor and agents are bounded by a read budget and report their coverage instead of silently truncating.

Evidence you can follow

References identify resource, graph, scope, expected type at an exact schema version, and a snapshot pin; cross-domain references require a pinned, scoped, authorised resolver. That gives every creative decision a chain back to evidence: a FramingTarget is grounded in an evidence pin that resolves to a pinned perception observation of a visual track; a caption token derives from a pinned speech observation; a visual placement uses a pinned media source whose asset metadata and SHA-256 are retained in the accepted snapshot. Labels like subject_1 are producer-local annotations, never identities.

Exact time, explicit clocks

All extents are non-empty half-open intervals [start, end) in Decimal seconds, so arithmetic never drifts through floating point. Clocks carry a timescale for exact tick conversion; source clocks, the assembled timeline clock and producer clocks are distinct, and producer output needs a proven mapping before it can be reused against a source. Composition semantics enforce legal containment — a caption token only inside a cue, a crop trajectory only inside a framing window — and that every contained extent stays within its parent.

Versions that never change meaning

Schemas have exact namespace and version identities and import exact versions. Each compiled schema has a fingerprint that includes imported meaning and ignores declaration order; registration checks the current fingerprints against a published ledger, so a published version cannot silently change. Older vocabularies stay as historical contracts and are converted explicitly — never modified in place.

The same declarations generate the wire catalogue and TypeScript read contracts for the web editor; int64 and Decimal values travel as strings so JavaScript never loses precision.

Proposals versus accepted history

Graph change sets carry a base snapshot and explicit existence preconditions, and apply atomically to a copy — but they are only proposals. Accepted history has exactly one authority, the authoring gateway, which appends revision N+1 against expected revision N. Agents can reason over the graph freely; they cannot write to it.

Implementation notes

Where this came from

The approach carries over from my knowledge-representation work at Codet AI — ontologies, typed relationships and constraint validation — applied to time-based media instead of code.

Scope

The kernel validates structure; it does not authorise storage access or prove evidence bytes exist — hosts supply truthful coverage and scoped resolvers. Legacy clips are adopted into unified history explicitly rather than assumed to have it.
