Architecture decisions

I kept Clyflo a capability-oriented modular monolith: one deployable codebase, grouped by business capability, with runtime-specific entry points for the API, workers and scheduler. That avoids distributed-data failure modes while cutting coupling. Each capability exposes a small public API, and nothing else may import its internals. There is one PostgreSQL database; a capability owns its writers and transaction rules rather than its own store.

Durable jobs are treated as compatibility contracts — job types, payload meanings, lease fencing, retries and cancellation evolve compatibly while rows may still exist. The API image is verified not to import worker-only ML and media dependencies. And legacy code is retired only with evidence: an owner, a replacement, a consumer audit, a production telemetry gate where relevant, a compatibility reader and a rollback path.

One accepted history for humans and AI

Every supported edit on an adopted clip goes through the authoring gateway as a command carrying an expected revision and a stable command ID. The host rechecks ownership, locks the relevant resources, validates dependency pins, and atomically writes the new revision, references, receipt and head. An identical retry returns the original receipt; reusing an identity with different input conflicts; a stale command cannot overwrite newer work. Historical snapshots keep exact asset and renderer dependencies, and adoption of legacy clips is explicit.

Orchestration and model operations

Automation stores versioned definitions, run state, child-job identities and checkpoints, and delegates to discovery, editor and publishing through public interfaces. Clip approval is tied to the relevant revision, rendered output and destinations, with safeguards against repeated scheduler ticks and stalled work.

Model calls go through explicit task routes and a central metering wrapper; text and vision concurrency are bounded independently, and usage accounting keeps provider attempts and spend even when a paid response fails local parsing. Gemini is the single provider, behind adapter contracts.

Jobs that survive interruptions

A PostgreSQL queue claims jobs atomically with FOR UPDATE SKIP LOCKED, with leases, heartbeats and recovery. General and RAVA work run in separate ECS worker pools. The release pipeline builds commit-tagged images behind CI; deployment takes a database snapshot, runs migrations, checks readiness, runs smoke tests and keeps rollback references.

Deterministic rendering and audio

Export reuses tested primitives instead of one giant filter graph: one ffmpeg pass trims and concatenates the spans, a second fits the frame onto the canvas with a blurred or solid background. Captions are then burned only by the native Skia caption engine, so there is exactly one caption renderer. A post-render audio mix ducks the original speech under background music and blacks out ranges the user removed; when there is no music and nothing removed, the pass is skipped and the output is byte-identical to before music existed.

Publishing and provider integration

A publish request is an immutable intent with independent state per destination, each in its own asynchronous job, so one platform’s failure does not erase another’s result. An uncertain upload is marked ambiguous and needs reconciliation or an operator decision rather than a blind retry. Integrations include OAuth connections, capability checks, history import, analytics and provider-specific workflows; a YouTube scope audit exercised uploads, captions, comments and analytics on a controlled account with a fresh two-scope grant.

Implementation notes

Why jobs live in PostgreSQL

Job state, editor state and receipts share one transactional store, so “commit the edit and mark the job done” is atomic. The trade-off is a lower throughput ceiling than a dedicated queue service.

Scope

Queue claiming alone is not exactly-once execution — durable retries rely on idempotent handlers. Controlled-account provider tests are not the same as broad platform approval.
